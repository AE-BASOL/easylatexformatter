# Easy LaTeX Formatter

Paste LaTeX source, run a best-effort deterministic formatter, then copy or download the result.

Phase 1 is intentionally small: it provides a minimal utility interface and a basic LaTeX indentation formatter. Advanced LaTeX formatting comes later.

## Local Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Test

```bash
npm test
```

## Scope

- Source formatting only.
- No AI rewriting.
- No PDF preview.
- No accounts or saved documents.
