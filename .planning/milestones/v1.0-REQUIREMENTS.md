# Requirements: Easy LaTeX Formatter

**Defined:** 2026-06-24
**Core Value:** User can paste LaTeX source, click format, and copy a cleaner version in one quick flow.

## v1 Requirements

### Input

- [x] **INPT-01**: User can paste or type LaTeX source into a large input area.
- [x] **INPT-02**: User can clear the input without refreshing the page.
- [x] **INPT-03**: User can load a sample LaTeX snippet to understand expected usage.

### Formatting

- [x] **FORM-01**: User can run formatting with a visible Format command.
- [x] **FORM-02**: Formatter applies deterministic indentation for common LaTeX environments.
- [x] **FORM-03**: Formatter preserves comments and protected verbatim-like blocks.
- [x] **FORM-04**: User can choose basic formatting options for indentation and wrapping.
- [x] **FORM-05**: App reports formatter diagnostics without deleting the original input.

### Output

- [x] **OUTP-01**: User can view formatted output with whitespace and line breaks preserved.
- [x] **OUTP-02**: User can copy formatted output to the clipboard.
- [x] **OUTP-03**: User can download formatted output as a `.tex` file.
- [x] **OUTP-04**: User can see whether formatting changed the input.

### Quality

- [x] **QUAL-01**: Formatting behavior is covered by fixture tests for documents, lists, math, tables, comments, and nested environments.
- [x] **QUAL-02**: Main paste-format-copy flow works on desktop and mobile viewport widths.
- [x] **QUAL-03**: Formatter engine is isolated behind an adapter so implementation can be replaced.

## v2 Requirements

### Editing

- **EDIT-01**: User can compare input and output in a diff view.
- **EDIT-02**: User can use keyboard shortcuts to format and copy.
- **EDIT-03**: User can upload a `.tex` file instead of pasting source.

### Engine

- **ENGN-01**: App can use `tex-fmt` or another proven formatter engine through the adapter.
- **ENGN-02**: App can expose table formatting if the engine supports it.
- **ENGN-03**: App can run formatting fully client-side when engine packaging allows it.

## Out of Scope

| Feature | Reason |
|---------|--------|
| AI rewriting | User selected deterministic local formatting for v1. |
| PDF compilation preview | Not needed for paste-format-copy core value. |
| User accounts | Adds friction and does not help one-shot formatting. |
| Cloud document storage | Privacy and scope cost outweigh v1 value. |
| Prose-to-LaTeX generation | User chose LaTeX source formatting. |

## Acceptance Criteria

- User can complete paste -> format -> copy without leaving the page.
- Empty input shows a useful validation state.
- Formatting failure preserves original input and explains the failure.
- Output can be copied and downloaded after successful formatting.
- Tests cover representative LaTeX formatting fixtures.
